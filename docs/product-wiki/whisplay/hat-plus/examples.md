# Whisplay HAT+ Project Demos

Explore projects built with the Whisplay HAT+ display, touch, audio, sensors, RGB LED, button, and Grove interfaces.

## Offline AI Translator with Gemma

This project rebuilds Google's open-source offline translator on a Raspberry Pi with Whisplay HAT+. It adapts the interface for touch, displays the time used by each translation stage, supports language switching, and performs translation entirely offline.

## Portable Flight Radar and AI Sky Console

This handheld console receives live commercial-aircraft telemetry with an SDR receiver and presents it through a retro air-traffic-control interface. A Raspberry Pi, 3D-printed enclosure, physical controls, Whisplay HAT+, and local AI also let the user talk to a simulated flight crew using the live flight data.
